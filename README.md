A one-line resignation letter from a cron job that has run every minute since March — 110 characters, written by a small deterministic Python program for make.fun's "The Funniest One-Line Resignation Letter" bounty, $10 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the entry to `out/entry.txt` (or `/output/entry.txt` when run in the grader).
